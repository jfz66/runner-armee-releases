# Runner d'Armée — téléchargements

Ce dépôt contient seulement les versions installables du jeu (le code est ailleurs).

**Installer sur Android :** ouvre la [dernière version](https://github.com/jfz66/runner-armee-releases/releases/latest),
télécharge `runner-armee.apk`, ouvre le fichier et autorise l'installation depuis ton navigateur quand Android le demande.
