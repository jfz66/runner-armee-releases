# Runner d'Armée — téléchargements

Ce dépôt contient seulement les versions installables du jeu (le code est ailleurs).

**Installer sur Android :** ouvre la [dernière version](https://github.com/jfz66/runner-armee-releases/releases/latest),
télécharge `runner-armee.apk`, ouvre le fichier et autorise l'installation depuis ton navigateur quand Android le demande.

## Mises à jour automatiques (recommandé)

1. Installe [Obtainium](https://github.com/ImranR98/Obtainium/releases/latest) (fichier `app-arm64-v8a-release.apk` pour la plupart des téléphones).
2. Sur le téléphone, ouvre ce lien : **[Ajouter à Obtainium](https://apps.obtainium.imranr.dev/redirect?r=obtainium://add/https://github.com/jfz66/runner-armee-releases)**,
   puis touche *Ajouter* dans Obtainium (ou colle l'adresse `https://github.com/jfz66/runner-armee-releases` dans *Ajouter une appli*).
3. Obtainium vérifie régulièrement les nouvelles versions et propose de les installer d'un toucher.

Si le jeu est déjà installé, Obtainium le reconnaît : les mises à jour s'installent par-dessus, sans perdre la progression.
